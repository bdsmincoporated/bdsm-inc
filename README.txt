BDSM INC. — STATIC WEBSITE PROTOTYPE

Files:
- index.html: website and client intake form
- styles.css: responsive brutalist-noir styling
- script.js: interactive catalogue, mobile menu, progress meter, validation and demo confirmation

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.

Important:
This is a front-end prototype only. The form does not send or store data. Do not enter real sensitive personal information. A production deployment needs a secure backend, appropriate access controls, data retention policy, privacy notice, and secure handling of sensitive data.

Visual direction: strict black and white only, with hard contrast, square edges, heavy rules, oversized typography, and a stark brutalist layout.
